>_ expgymPython ≥ 3.7 · NumPy
Clone the repo. Install the core.
# 1. Clone
git clone https://github.com/tiannuo-yang/expgym.git
cd expgym

# 2. Install
python -m pip install -e .

Core dependency: NumPy. Python 3.7+ and Git required.

Three budgets. One command.
# 3. Evaluate with a scripted agent
python -m expgym run --task toy \
  --backend scripted --output runs/smoke

# Inspect scores
python -m expgym summarize runs/smoke
✓3 regimes · JSON traces + scores<1s*

*Local scripted smoke run; excludes installation. Real-model evaluations take longer.

After installation · run from the repo
# Download audit data once
python scripts/download_data.py --only audit

export EXPGYM_API_KEY="your-api-key"
python -m expgym run --task audit \
  --items 0 --repeats 1 --regimes tight \
  --model your-model \
  --base-url https://your-endpoint/v1 \
  --output runs/demo

Use your model ID, endpoint and key. Feedback is simulated; model API time and usage still apply.

Run 4 agents with PoolAct
Same data, model and API key
python -m expgym pool --task audit \
  --items 0 --regimes tight --agents 4 \
  --strategies poolact --model your-model \
  --base-url https://your-endpoint/v1 \
  --output runs/pool
